# Research sources

Two lists, kept strictly apart.

The first is what has **actually been fetched and read** while writing the
library. Only these may be cited in a drill's `sources[]`. The second is a list of
candidates nobody has consulted yet — it is a to-do list, not a bibliography, and
**nothing in it may appear as an attribution.**

The attribution rule this file exists to enforce: *a named coach or body appears
in a drill's sources only if a permitted page documenting that drill or pattern
was actually fetched. A failed fetch means no attribution — never a best-guess
URL.*
